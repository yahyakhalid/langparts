كيف تبدأ مشروعك الأول على GitHub

في هذا الدرس سنستخدم Visual Studio Code محرراً للكود، ونحفظ العمل على GitHub ثم ننشر الصفحة عبر GitHub Pages. جرّبنا الخطوات على iPhone 15 Pro وعلى حاسوب يعمل بنظام Windows 11.

تحتاج إلى Node.js الإصدار 20 أو أحدث، ومدير الحزم npm، وبعض المعرفة بلغتي HTML وCSS. سنكتب الواجهة بمكتبة React Native ونختبرها على Google Chrome وMicrosoft Edge.

ثبّت الحزمة بالأمر npm install --save-dev typescript eslint prettier ثم اضغط Ctrl + Shift + P لفتح لوحة الأوامر. ملف الإعدادات موجود في /etc/nginx/sites-available/default. 

function greet(name) {
  // Say hello to the user in the console
  console.log("Hello, " + name + "! Welcome to the project.");
}

راسلنا على support@example.org أو زر الرابط https://example.org/docs/getting-started?lang=en وتابع الوسم #OpenSource والحساب @example_dev.

الإصدار الحالي هو v2.3.1-beta وحجمه 12 MB، ويدعم منفذ USB-C وتصدير الملفات بصيغة PDF عبر واجهة REST API.
